# Pandas & NumPy Practical Tasks

Practical tasks completed during my Data Analyst internship to practice working with data using **Pandas** and **NumPy**.

## Topics Covered

* Data loading and inspection
* Filtering and boolean indexing
* Grouping and aggregation
* Working with categorical data
* NumPy arrays and operations
* Basic data analysis

## Structure

* `assignment_pandas_done.ipynb` — completed Pandas practical tasks
* `assignment_numpy_done.ipynb` — completed NumPy practical tasks
* `data/` — datasets used in the tasks
